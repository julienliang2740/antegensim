# Category A (Skills): sweep notes

Scenario files are generated by a scratch script (gen.py + skills.py in the sweep-A scratchpad); seeded
skills were checked with fake-scripted runs (goto/eat_here/tour/patrol run for many turns and absorb fruit).
The engine cannot place plants at given points, so "rows" use `plants_at_agent_starts`: one tree per agent
start cell (agents placed in rows), the rest uniform.

## Design intent (v1)

* **A1v1 Orchard rows** (16: 15 Haiku + a16 Sonnet, 80 rounds, 30x30). Agents stand on two tree rows
  (y=5 and y=-5, x=-12..9 every 3), 40 trees total. Mature fruit every 8 rounds (slow), 2 ripe at start.
  Cognition 3x (input 0.0006, gen 0.003), `action_discount` 0.5, move 4. Seeded step/goto/eat_here; the
  persona tells them to write a looping `tour(route, laps)`. Vision 2, comm 5, attack same-point.
* **A2v1 Expensive minds** (12 Haiku + a13 Sonnet, 100 rounds, 21x21). Pairs share 7 start trees, 20
  trees total, fruit every 5 rounds. Cognition 5x (input 0.001, gen 0.005), discount 0.6,
  `skill_count_limit` 8. Seeded single-shot `forage(spot)`; persona says write a loop.
* **A3v1 Guild of scripts** (20 Haiku, 70 rounds, 25x25). Teachers a01-a03 own step/goto/eat_here/tour;
  17 learners own nothing. send 0.5, broadcast 1.5, comm range 30, 600-token messages, transfer at any
  distance, query anywhere, `include_skill_source` true. Cognition 3x, discount 0.5, fruit every 6 rounds.
* **A4v1 Patrol and ambush** (20 Haiku, 70 rounds, 25x25). 14 trees uniform (not at starts), attack
  within vision 3 (`attack_requires_same_point` false), attack_cap 40, query anywhere,
  `interrupt_on` damage. Cognition 2x, discount 0.6. Seeded step/goto/patrol (patrol returns when it
  meets an agent); persona hints flee/hunt/guard skills.

## Judgements

* **A1v1 r47**: via-skill 97% (48 model decisions in 47 rounds for 16 agents), every agent saved and ran
  its own `tour`, but 0 messages / attacks / transfers: skills are never interrupted (`interrupt_on` []),
  so agents never think, and they all tour whole rows together in a conga line. Compute diverging (66 to
  249), no deaths yet. Kept running (cheap, ~$0.5) to see late hunger. -> **A1v2**: `interrupt_on`
  message+damage, send 1 / broadcast 2 / comm 6, 26 trees (10 wild instead of 24), each keeper told its two
  claimed home trees, 3 raiders (a03, a11, a15).
* **A4v1 r10**: 120 of 176 actions `observe`, 1 patrol run, 0 contact. Trees at unknown uniform points
  (`plants_at_agent_starts` false), so patrol has no route and agents search blindly. -> **A4v2**: 10 known
  trees at start cells, 2 agents per tree, 4 wild, all tree points listed in the persona.
* **A2v1 cut at r71**: 12 of 13 agents wrote and ran their own loop (harvest_loop, farm_loop, eat_loop...;
  via-skill 91%, 112 model decisions in 71 rounds). The one agent that never looped (a10) starved at r44.
  Thesis confirmed, but 0 messages/attacks/transfers: every pair looped on its own tree and never needed
  anyone; flat for 40 rounds. -> **A2v2**: 11 trees (7 shared start + 4 wild), fruit every 6,
  `interrupt_on` message+damage, send 1 / broadcast 2 / comm 6, attack within vision 2 (cap 40), 3 bandits.
